# 记单词

一个可以离线使用的背单词网页应用。支持小学 / 初中 / 高中 / 大学四套词库，
卡片记忆 + 拼写测试 + 打卡统计。

## 用法

打开 https://swfsf.github.io/wordbook/ 直接用。

手机上打开后，可以用浏览器的「添加到主屏幕」把它装成一个 App，
装好之后断网也能用。

## 功能

- 四套内置词库（小学 108 / 初中 113 / 高中 222 / 大学 210），另有「全部混合」自动去重
- 卡片式学习：点一下才显示释义，例句里的目标单词会高亮
- 每组 10 个词，一组过完自动进入拼写测试
- 不记得的词会在本组内再考一次
- 连续答对 3 次算掌握，之后不再出现
- 学习进度、拼写记录、打卡天数都保存在本机浏览器里
- 「我的词库」支持自己粘贴单词，格式 `英文, 中文`（逗号、等号、制表符都行）
- 可离线使用

## 快捷键

`空格` 显示释义　`←` 不记得　`→` 记得　`P` 朗读
